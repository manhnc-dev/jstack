## Conventions

- Branch names: no enforced pattern; mostly `feat/`, `fix/`, `chore/`, `ci/` prefixes. jstack uses `jstack/<slug>/plan` and `jstack/<slug>/pr-n`
- Commit style: Conventional Commits with scope, optional Linear ticket in parentheses, then PR number, e.g. `fix(auth): subject (ODD-1089) (#97)`
- PR template: none
- Layering: controller to service to repository, with model/dto and MapStruct mappers; some feature-sliced packages
- DI and errors: Lombok (`@RequiredArgsConstructor`, `@Slf4j`) constructor injection; custom exceptions in `com.pass.acme.exception` (`AcmePassException` family: `UnauthorizedException`, `BadRequestException`); controllers return `ApiResponse` wrappers and `log.warn` on handled errors
